## ✨ Features

- 🎨 Custom-designed hero section with animated blobs and a twinkling star field
- 🌙 Light / dark mode toggle with a smooth animated transition
- 🧰 "Developer Toolkit" card — an at-a-glance view of my backend, frontend and AI-productivity stack
- 📁 Featured Projects grid with live demo + GitHub links per project
- 🛤️ Engineering Journey timeline — from BCA fundamentals to backend + AI/ML exploration
- 🏆 Awards & Achievements section
- 📊 Live GitHub activity stats (public repos, followers, following)
- 📬 Contact section with direct links (GitHub, LinkedIn, email, phone)
- 🎬 Scroll-reveal animations as sections enter the viewport
- 📱 Fully responsive, mobile-first layout
- 🔍 SEO-ready — meta description, keywords, Open Graph tags, and `sitemap.xml`

## ⚙️ Running Locally

Since it's a static site with no build step, you only need a local server:

```
git clone https://github.com/GouravK1107/my-portfolio.git
cd my-portfolio
python -m http.server 8000
```

Open
```
http://localhost:8000
```
